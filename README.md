# Tournament Tracker Frontend
Клієнтська частина платформи для управління студентськими кіберспортивними турнірами. Додаток взаємодіє з Django REST API бекендом.

## Використані порти та адреси
- **Бекенд:** http://localhost:8000
- **Фронтенд:** http://localhost:5500

## Як запустити проєкт
1. Клонуйте репозиторій:
```bash
git clone https://github.com/burdeynainnaa/rest-api-frontend
cd rest-api-frontend
```
2. Відкрийте файл index.html у браузері або запустіть його через локальний сервер
3. Переконайтеся, що локальний бекенд-сервер запущений на порту 8000, і натисніть кнопку «Завантажити турніри», щоб перевірити отримання даних через API.

## Використання штучного інтелекту

- **Які інструменти ви використовували?**  
  Штучний інтелект (gemini)
- **Що саме зробили з їхньою допомогою?**  
  ШІ допоміг написати клієнтську частину (фронтенд), підказував із виправленням помилок на бекенді та допоміг розібратися зі структурою Postman.
- **Як перевірили результат?**  
  Результат перевірено за допомогою офіційного скрипта `python check_submission.py`, проходження статичного аналізу й форматування, а також шляхом ручного тестування всіх ендпоінтів через Postman і перевірки зв'язку фронтенду з бекендом у браузері.
