# Tournament Tracker Frontend
Клієнтська частина платформи для управління студентськими кіберспортивними турнірами. Додаток взаємодіє з Django REST API бекендом.

## Використані порти та адреси
- **Бекенд:** http://localhost:8000
- **Фронтенд:** http://localhost:5500

## Як запустити проєкт
1. Клонуйте репозиторій:
```bash
git clone https://github.com/burdeynainnaa/rest-api-frontend
cd rest-api-frontend
```
2. Відкрийте файл index.html у браузері або запустіть його через локальний сервер
3. Переконайтеся, що локальний бекенд-сервер запущений на порту 8000, і натисніть кнопку «Завантажити турніри», щоб перевірити отримання даних через API.

## Основний функціонал
1. **Сторінки та розділи:**
   - **Головна:** Перегляд списку доступних турнірів для всіх відвідувачів.
   - **Реєстрація:** Форма реєстрації з полями `username`, необов'язковими `first_name` та `last_name`, `email`, `password` та `password_confirmation`.
   - **Логін:** Вхід у систему з надсиланням запиту на отримання JWT-токенів (`access` та `refresh`).
   - **Панель управління:** Захищена зона для створення нових турнірів.
   - **Вихід:** Завершення сеансу з очищенням локального сховища та поверненням на головну сторінку.

2. **Поведінка та безпека:**
   - **Захист маршрутів:** Неавторизовані користувачі при спробі відкрити панель управління автоматично перенаправляються на сторінку логіну.
   - **Збереження редиректу:** Після успішного входу застосунок автоматично повертає користувача на ту сторінку, яку він намагався відкрити.
   - **Динамічний Navbar:** У навігаційній панелі гості бачать кнопки входу та реєстрації, а авторизовані користувачі — своє ім'я та кнопку виходу.
   - **Автоматичний Refresh Token:** У разі закінчення терміну дії `access`-токена (статус `401 Unauthorized`) фронтенд автоматично оновлює його за допомогою `refresh`-токена у фоновому режимі, не змушуючи користувача логінитися знову.
